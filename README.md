One line of out-of-office auto-reply, written to be funny, for
[The Funniest Out-of-Office](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf)
on make.fun. The program writes that line to `/output/entry.txt`,
a single line of 140 characters or fewer, nothing else.

## Run it

```sh
python3 main.py
# writes /output/entry.txt
```
